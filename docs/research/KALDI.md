3. `<select name="standard1Cd">` に `value="MAME"`（豆）がある商品のみ採用
4. レート制限: **1 req/sec**

## 4. 商品ページのデータ構造（スクレイピング用）

### 4.1 HTML セレクタ

| フィールド | セレクタ / ソース |
|------------|-------------------|
| 商品名 | `input[name=productName]` / `h1.headline` |
| 価格 | `#standardMtx_{n}_0_0_SellingPriceIncTax` / `#hidSinglePrice` |
| 説明 | `meta[property=og:description]` / `meta[name=description]` / **`pro_detail_headline*_style` + `pro_detail_desp*_style`** |
| 容量 | 商品詳細テーブル「内容量」 |
| 商品画像 | `meta content=... property=og:image`（属性順序に注意）/ `/ec/img/{dir}/{product_id}_M_1m.jpg` |
| 焙煎 | 商品詳細テーブル「ロースト」 |
| 生産国 | 商品詳細テーブル「生豆生産国」 |
| テイスト | 商品詳細テーブル「テイストバランス」 |
| ホール豆可否 | `select[name=standard1Cd] option[value=MAME]` |

### 4.2 挽き方オプション（全焙煎珈琲共通）

プルダウン `standard1Cd` から選択:

- 豆（MAME）← **DripLab 対象**
- フィルター用（中挽き）
- エスプレッソ用（極細挽き）
- 水出し用（細挽き）
- プレス用（粗挽き）

**DripLab へのマッピング**

| カルディ「ロースト」 | roast_level |
|---------------------|-------------|
| 中煎り | medium |
| 中深煎り | medium_dark |
| 深煎り | dark |

| カルディ「テイストバランス」 | acidity | body | bitterness | sweetness |
|---------------------------|---------|------|------------|-----------|
| 爽やかな酸味 | 高 | 中 | 低 | 中 |
| やわらかな甘み | 中 | 中 | 低 | 高 |
| 強い香りと苦み | 低 | 高 | 高 | 低 |

## 5. EC に含まれない商品（参考）

- 店舗レジ・店頭焙煎コーナー限定の季節豆（EC 未掲載の場合あり）
- ドリップバッグ・リキッド等（別カテゴリ `11010200000` 以降）
- フレーバーコーヒー（`11010B00000`）

**対応**: DripLab は購入 URL 必須のため、カテゴリ `11010100000` の EC 掲載品を正とする。

## 6. スクレイピング実装

### 6.1 推奨フロー

```
1. GET /ec/Facet?category_0=11010100000&page={n}
2. /ec/pro/disp/1/{id}?sFlg=2 リンクから ID 収集
3. 各 detail で MAME（豆）オプションを確認
4. 正規化 → data/seeds/kaldi.beans.seed.json
```

### 6.2 スクリプト

| ファイル | 用途 |
|----------|------|
| `scripts/scrape_kaldi_beans.py` | フル取得（`--full`）または既存 raw の enhance（デフォルト） |
| `data/scraped/kaldi/beans_raw.json` | raw 出力（44 件） |
| `data/images/kaldi/{product_id}.jpg` | 商品画像（44 件） |

**enhance モード（デフォルト）** で既存 `beans_raw.json` に対し:

- 詳細ページから `pro_detail_*` ブロックで説明文を補完（旧: テイスト表のみの 36 件を改善）
- null 価格の再取得（2026-08-08 時点: **0 件**）
- `image_url` / `image_local` 付与

### 6.3 raw JSON フィールド（追加分）

| フィールド | 例 |
|------------|-----|
| `image_url` | `https://www.kaldi.co.jp/ec/img/050/4515996019050_M_1m.jpg` |
| `image_local` | `data/images/kaldi/4515996019050.jpg` |

### 6.4 注意事項

| 項目 | 対策 |
|------|------|
| レート制限 | 1 req / 1 sec 以上 |
| セール価格 | `standardMtx_*` の非ゼロ値を採用 |
| meta description 空 | テイストバランス + 生産国でフォールバック |
| 冬季名称 | アイスブレンド ↔ イタリアンロースト の表記ゆれ |
| 法務表示 | 「出典: カルディオンラインストア（取得日）」 |
